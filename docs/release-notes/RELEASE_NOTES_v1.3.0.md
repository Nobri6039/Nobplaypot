# Nobplaypot v1.3.0

上一版（v1.2.4）之后的全部更新。这一版把产品从「共享视频」推进到「共享音视控」：
启动不再直接进播放器，应用共享换成自研的帧直传链路，控制权限改为按成员逐个授权。

## 新增

### 主菜单与三种界面

- **启动页改为功能主菜单**：媒体播放 / 应用共享 / 浏览器同步 / 加入房间 四张卡片，底部「仅本地播放 / 设置 / 查看日志」。不再一打开就是播放器。
- **三种界面按场景自动切换**：
  - `主菜单`：启动、停止会话后；
  - `播放器`：只有媒体播放（本地或媒体房间的房客）才会进入；
  - `共享会话`：应用共享 / 浏览器同步（主持与房客都进这个界面）。
- **专属共享界面**：左侧状态卡（标题、房间人数、端口、画面尺寸、帧大小、编码耗时），右侧房间聊天，底部「房间成员 / 停止共享（或退出房间）」。
- 「媒体播放」卡片改为**先开房再选文件**；只想自己看时用底部的「仅本地播放」。
- 播放器左下角新增「结束并返回主菜单」，任何路径回到主菜单都会自动结束残留会话。

### 应用共享：自研帧直传（不再依赖 ffmpeg + VLC）

- 链路：GDI 抓屏 → StretchBlt 缩放 → GDI+ **JPEG** 编码 → UDP 分片 → 客户端 GDI+ 解码 → 直绘。
- **客户端不再用 VLC 播放器**：没有 400ms 级缓冲，也没有 VLC 子窗口带来的黑屏 / 崩溃问题。
- 实测（1280×720 / 30fps / q70）：编码 14.8 ms/帧、55 KB/帧、**端到端 16.9 ms（max 17.0）**；60fps 目标实测 51.6fps。
- **静止画面跳过编码**：把画面缩到 160×90 取 CRC 比对，相同就跳过编码与发送（每 1 秒仍强制发一帧给新加入者）。实测静态 4 秒只发 9 帧。
- **缩放 25%–200%**：按比例重抓整幅画面，客户端窗口跟着变大变小，1:1 显示、不裁剪不拉伸；点击坐标自动跟着缩放。
- **后台捕获**：默认用 `PrintWindow` 让窗口自己把画面画进来，被别的窗口盖住、或者没有焦点也能抓到完整画面；老版屏幕 `BitBlt` 保留为可选（共享对话框的「后台捕获」开关、设置里的「捕获方式」）。窗口最小化时 Windows 不再合成，任何方式都抓不到，这种情况会自动退回屏幕采集并在日志里说明。
- 共享窗口被关闭时，主持端**自动广播并结束房间**，房客自动退出。

### 输入与控制

- 支持鼠标左/右/中键、滚轮、拖动、键盘，以及**输入法/粘贴文本通道**（底部输入框回车发送，中文可直接落到主持端）。
- 控制权改为**按房间成员逐个授权**（默认只读）：创建共享时不再询问；房客无权限时主持端拒绝注入，**客户端本地也不捕获事件、输入框隐藏**。
- 拖动时会固定向按下时的子窗口发送移动事件，拖拽不再中断。
- 悬停/移动：修复了绘制子窗口吞掉鼠标事件的问题（`WS_EX_TRANSPARENT`），悬停高亮可以同步。

### 设置

- 设置窗口拆成 7 个选项卡：常规 / 外观 / 聊天室 / **流式传输（共用）** / **媒体播放** / **浏览器同步** / **应用共享**。
- 应用共享可调：传输方式（帧直传 / ffmpeg+VLC）、采集帧率、画面编码（JPEG/PNG）、JPEG 质量、最大抓取宽度、操作注入方式、默认缩放。
- 浏览器同步可调：同步轮询间隔、允许的进度偏差、起始网址（新增 `web_sync_interval_ms` / `web_sync_tolerance` / `web_start_url`）。

### 日志

- **按角色分文件**：`nobplaypot-host.log` / `nobplaypot-client.log`，启动阶段仍写 `nobplaypot.log`。
- **每行毫秒时间戳**，并新增 `[lat]` 系列阶段日志（`client.join` / `app_offer.recv` / `frames.start` / `frames.stats` / `frames.recv` / `app_view`）与 `[appinput]` 四段链路（capture → send → host.recv → inject，带端到端毫秒差）。

### 启动器 / 发布

- 启动器版本资源升级到 **1.3.0.0**。
- 生成新的 RSA-2048 密钥对：公钥编译进 exe，私钥保留在 `launch/tools/private-key.xml`（不随包发布）。
- `Bin\payload.manifest` + `payload.sig` 需要在本版文件就位后重新生成（`tools\sign.ps1`）。
- 补齐了 `Bin\Nobplaypot.pyw` 入口（此前缺失，启动器会报 “script 不存在”）。
- 实测：启动器校验 286 个文件的签名与哈希通过，正常拉起 `pythonw` 并进入主菜单。

## 修复

- 一次点击变两次、一次按键出两个字符（键盘重复绑定 + 未去重的 `WM_CHAR`）。
- 应用共享“点了没反应 / 只有中心能点”（DPI 折算、缩放裁剪、子窗口吞事件）。
- 共享窗口名在客户端的标题栏与内部标题里重复显示。
- 缩放超过 100% 时窗口不变、画面被裁。
- 关闭共享窗口后房间不结束。
- 回到主菜单但会话仍在，导致主菜单其他功能被“请先结束当前会话”挡住。
- 小数类设置被取整（`web_sync_tolerance=1.5` 存成 2、`app_zoom=1.25` 变 1）。
- 入口脚本里重复写了两遍 `if __name__ == "__main__": main()`，退出后会自动再启动一次。

## 已知限制

- 应用共享的控制依赖窗口消息：微信、多数游戏、部分 Electron/自绘程序不处理合成消息，仍然只能观看（这是消息注入的固有限制，除非改成移动物理光标的 `sendinput`）。
- 中文输入走底部输入框的文本通道；直接抓键盘按键无法得到输入法组字结果。
- 浏览器同步仍受站点限制：部分站点禁止修改 `playbackRate` 或拦截 `currentTime` 跳转。
