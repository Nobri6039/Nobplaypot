# Nobplaypot v1.2.4

上一版（v1.2.3）之后的全部更新。

## 新增

- **房客控制权限（默认只读）**：成员列表每行在「踢出」左侧新增「只读 / 可控制」开关。只读房客的 12 类控制指令（seek、rate、play、pause、toggle、seek_rel、seek_ratio、volume、mute、stop、web_cmd、web_url）在主持端入口即被拒绝，房客端控件同步灰化。
- **浏览器内反向同步**：房客在网页里拖动进度、修改倍速、暂停/继续，由「预测偏差」算法识别并上报主持，不再被主持端的旧状态覆盖。
- **同步模式单一权威**：浏览器同步进行时，主窗口的打开文件、播放/暂停、上一集/下一集、停止、音量、倍速、进度条全部灰化并屏蔽（含空格、方向键、滚轮），退出会话时恢复。
- **19 阶段 `[seek]` 诊断日志**：进度链路每一跳都有记录，可直接判断断点位置。
- **完整双语界面**：窗口标题、对话框标题、Canvas 动态文案一并翻译（375 条字面量 / 285 个键）。
- **设计文档**：新增 `docs/design-supplement.md`，说明权限模型、反向感知与界面态设计。

## 修复

- 退出全屏后主窗口永久置顶（Tk 的 `-fullscreen` 会留下 `WS_EX_TOPMOST`，现已在退出时彻底清除）。
- 房客改倍速被 seek 重置（改为只设置 `playbackRate`，不再重设 `currentTime`）。
- 房客加入浏览器同步房间不打开浏览器（welcome 分支结构错误）。
- 暂停/播放双端"鬼畜"（新增发令冷静期与回声抑制）。
- 英文界面残留中文：聊天计数、对话框标题、连接卡片、缓冲层、窗口标题、语言选项行等。

## 已知限制

- 浏览器同步仍受站点限制：部分站点禁止修改 `playbackRate` 或拦截 `currentTime` 跳转。
- 反向识别存在 200–600 ms 延迟；1.2 秒内的连续暂停/播放会被合并为一次。
