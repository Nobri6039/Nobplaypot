# Nobplaypot v1.5.0

产品定位已从「一起看视频」扩展为**局域网多人协同工具**：一起看视频、一起操作同一个软件、一起同步网页，
三种协同共用一个房间、一套密码与成员权限。

上一版（v1.3.0）之后的全部更新。这一版的技术主题是**后台捕获**和**延迟**：共享的窗口被别的窗口盖住也能抓、
缩放彻底交给房客本机、端到端延迟从 ~45ms 压到 ~25ms。

## 新增

### 应用共享：后台捕获（PrintWindow）

- 默认改用 `PrintWindow` 采集：让窗口自己把画面画进我们的位图，**被别的窗口完全盖住、或者没有焦点，也照样抓得到完整画面**。
- 先试 `WM_PRINT`（内容最全），画出来是纯色再试 `PW_RENDERFULLCONTENT`（走 DWM 表面，对遮挡最稳）；
  两种都拿不到内容就**自动退回屏幕 BitBlt**，并在日志里说明原因。
- 老版屏幕截图保留，两处可切换：
  - 共享对话框里新增「**后台捕获**」开关（默认开）
  - 设置 → 应用共享 → 「**捕获方式**」：`后台捕获 (被遮挡也能抓)` / `屏幕截图 (旧)`
- 每 5 秒的统计日志会带上 `捕获=printwindow|screen`，一眼看出当前用的哪种。
- **最小化仍然抓不到**：Windows 不再合成最小化窗口，这一点和 OBS 一样，任何方式都无解。

### 应用共享：缩放彻底改成房客本机

- 主持端**永远只传原画 100%**，不再跟着某个房客的缩放请求改采集尺寸。
- 房客点 ± 只改自己窗口，线性档位 **25 / 50 / 75 / 100 / 125 / 150 / 175 / 200%**，多人同时看互不影响。
- 加入时按**自己屏幕**自动挑一个装得下的档位（屏幕小就自动降到 50%/25%），并记一条 `[lat] frames.fit`。
- 直播窗口**禁止手动拉伸**（拉了就变形），尺寸只由缩放档位决定；放大用 HALFTONE 平滑、缩小用 COLORCOLOR 保速度。

### 延迟优化（实测 45~55ms → 25~28ms）

- **修掉客户端最大的坑**：只要目标窗口比帧大哪怕 1 像素就用 `HALFTONE` 插值，实测 15~24ms/帧；
  现在尺寸差 ≤2px 直接 `BitBlt`，只有放大 ≥2 倍才用 HALFTONE，贴图降到 **0.7ms**。
- HDC / 内存 DC 缓存复用，不再每帧 `GetDC`+`CreateCompatibleDC`+`DeleteDC`。
- 主持端 1:1 抓屏改 `BitBlt`（原 `StretchBlt` 13ms → 9.7ms）；静止判定指纹改成从**已抓下来的位图**算，
  不再二次读屏，抓取+编码 25~30ms → **17~19ms**。
- 客户端收包非阻塞 + 复用缓冲 + 一次收完，**只解码最新一帧**（队列最多留 2 帧），落后时直接跳到最新画面。
- 新增分阶段日志：`[lat] frames.recv … 分阶段 wire=… decode=… blit=…`，瓶颈一眼可见。

### 浏览器同步：起始页随程序走

- 起始页模板放进 `Bin\browser_start.html`，程序用**相对路径**读它。
- 运行时渲染一份到固定路径 **`C:\Temp\nobplaypot_start.html`**：浏览器的 `file://` 是绝对路径，
  主持与房客的安装目录往往不同，固定成同一个路径后，同步过去的网址两边都打得开。
- `C:\Temp` 不可写时退到 `%TEMP%\Nobplaypot\`，并写日志。
- 起始页进入 payload 清单参与签名校验，改了就起不来。

## 修复

- **共享对话框里「画质」下面只剩一个孤零零的「画质」二字**：画质下拉框创建后忘了 `pack()`，根本没显示出来。已修。
- 首次加入应用共享时窗口开的不是「主持端传过来的 100%」，而是被采集上限压过的小尺寸——采集上限不再压 100%。
- 点 ± 放大时窗口"连动都不动"：`最大抓取宽度` 把 `源宽×倍率` 夹死了（1279×1.25 被夹成 1280）。已按「只限制缩小」重做。
- 放大后百分比标签一直显示 100%（`apply_zoom` 覆盖了标签），已修。
- 英文界面里「标准/高/低」三档画质、后台捕获、捕获方式等文案补了翻译。
- 关闭共享窗口后房间不结束、回主菜单不结束会话（1.3.0 已修，这里一并列出）。

## 已知限制

- 相机/游戏这类**直接读原始输入**的程序仍然无法远程操作（微信实测无效），只能观看。
- 用 `PrintWindow` 时，D3D 直出画面（游戏、部分视频播放器）可能抓到黑屏，会自动退回屏幕采集。
- 跨进程 `PrintWindow` 会被 UIPI 拦截：如果本程序不是以正常权限启动（比如被降权运行），可能抓不到别的进程窗口。
- 浏览器同步受站点限制：部分站点禁止改 `playbackRate` 或拦截 `currentTime` 跳转。

## 升级说明

- 直接解压覆盖即可；`Bin\payload.manifest` / `payload.sig` 必须和同包的 `Bin\*.py` 一起替换，否则启动器拒绝启动。
- 启动器版本资源升到 **1.5.0.0**，需要重新编译 `launch\Nobplaypot.sln`。
