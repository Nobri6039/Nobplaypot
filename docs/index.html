FEATURES

一个房间，三种「一起」。

一起看视频、一起用同一个软件、一起逛网页 —— 房间、密码、成员、聊天全部共用，切模式不用换工具。

▶

一起看视频

主持选本地视频开房，房客加入后进度、暂停、倍速、音量实时同步；1x 播放走流复制，不重新编码。

🖥️

一起用同一个软件

把任意窗口的画面推给房客，鼠标、滚轮、键盘、输入法文字实时回传主持端——对方看到的就是你屏幕上那块，还能直接动手操作。

🌐

一起逛网页

内置 Edge 只同步网页地址与播放进度；房客在网页里拖动、改倍速、暂停也会反向上报给主持，两边始终在同一段。

🎯

按人授权操作

默认只读；在「房间成员」里给某个人单独开控制权，立即生效。没有权限的房客本地不捕获任何输入，底部输入框也隐藏。

🪟

后台捕获

默认 PrintWindow 采集：窗口被别的窗口完全盖住、或者没有焦点，也能抓到完整画面；遇到抓不到的程序会自动退回屏幕采集。

⚡

25ms 帧直传

抓屏 → JPEG → UDP 分片 → 客户端 GDI 直绘，不经过 VLC。720p/30fps 端到端实测约 25ms，静止画面跳过编码。

🔍

缩放是房客本机的事

25/50/75/100/125/150/175/200% 线性档位，只改自己窗口大小；主持端永远只传原画，几个人同时看互不影响，屏幕小会自动降档。

🔒

房间密码

可选密码，只保存在主持端，房客提交后由主持校验；常量时间比较，单个连接限次尝试。

👥

成员与踢出

成员列表实时同步，按加入顺序排列；主持可移除房客，房客离开不会打断其他人的画面与操作。

💬

聊天 + 弹幕

右侧聊天面板与主持端消息记录；新消息以弹幕从右向左飘过画面，窗口与全屏都生效。

⛶

全屏控制岛

鼠标靠近屏幕底部浮出圆角控制条；播放、进度、音量、倍速、退出全屏一应俱全，观影时不打扰画面。

📦

免安装 + 签名校验

内置最小 Python 与 VLC 运行库，解压双击即用；启动器先校验 287 个文件的签名与哈希，再拉起程序。

HOW IT WORKS

三步，把一台电脑变成一间协同工作室。

指令走可靠的 TCP，画面走低延迟的 UDP；房客的鼠标键盘再走 TCP 回到主持端，像坐在同一台机器前。

01

选一种协同

主菜单里选「媒体播放 / 应用共享 / 浏览器同步」，设好指令端口、画面端口和可选的房间密码，开始主持。

02

房客加入

房客填主持的地址，有密码先由主持校验。加入后按自己屏幕自动选一个放得下的显示倍率。

03

一起动手

看视频时同步播放；共享软件时房客的点击与敲字会送到主持端那块窗口；共享网页时两边进度对齐，谁都能拖。

指令通道

TCP · 换行 JSON

心跳、房间状态、密码校验、聊天、成员、播放控制，以及房客的鼠标键盘与输入法文字。断线自动重连。

→

画面通道

UDP · 帧直传

主持端抓屏后编码成 JPEG，按 1200 字节分片发出；画面没变化就整帧跳过，只发一帧保活。

→

本机呈现 + 操作回传

GDI · 按比例映射

客户端把帧直绘到自建窗口，缩放只改自己窗口的大小；点击位置按画面比例换算回源窗口坐标再注入。

FAQ

常见问题

房客真的能操作我的电脑吗？

能，但只限于你共享的那个窗口。共享默认是只读的，需要在「房间成员」里给某个成员单独开控制权；主持端只往那个窗口投递模拟消息，不会移动你的物理鼠标，也不会影响你桌面上的其他程序。

哪些程序不支持远程操作？

微信、多数游戏、部分 Electron / 自绘界面程序不处理合成的窗口消息，只靠消息注入无法操作，这类窗口只能观看。普通 Win32 / WinForms / 浏览器 / 编辑器一般都能正常操作。

共享的窗口被遮住或被最小化，还能看吗？

被别的窗口遮住可以：默认用 PrintWindow 让窗口自己把画面画出来，不看屏幕。被最小化就不行——Windows 不再合成最小化窗口，任何捕获方式都拿不到画面。

延迟大概多少？

应用共享在 720p / 30fps 下实测端到端约 25ms（抓屏 + 编码 + 传输 + 解码 + 贴图）。想要更跟手可以在设置里降低 JPEG 质量或帧率；换片、拖动这类操作是另一条可靠的 TCP 指令通道。

支持公网吗？防火墙要开哪些端口？

支持。主持端放行 TCP 指令端口 和 UDP 画面端口（浏览器同步只用到 TCP），映射到公网后房客填公网地址即可；房客这边只需要出站连接。

需要安装 VLC 或 Python 吗？

使用免安装版不需要，运行时已内置。从源码运行则需要 Python 3.10+ 与 64 位 VLC 3.x。
